    Icons

    Specify custom UI icons. Updating regenerates the PPUIPKG, deferred icon-mount manager, and Lua database registration together.

    Mod-wide. Gives every species a full set of placeholder icons borrowed from Allosaurus: the two PNG portraits the hatchery and notifications use (Dinosaurs_Small_ / Dinosaurs_Headshot_), plus the tech-tree SVG embedded into the .ppuipkg — SVGs cannot ship any other way. Replace the files under UI/ with your own art; regenerating never overwrites them, and custom SVGs already in the package are kept.

    Render Scaling (optional)

    Current render scale per family member. Each can be a fixed multiplier or a min/max band that every animal rolls inside.

    Hooks DinosaurUtils.InstantiateDinosaur and calls SetScale. Collision and pathing are NOT verified to follow the visual scale — roughly 0.5–0.6 is known good, larger values are lightly tested.

    Edit Built Mod

    Tune cosmetics in an already-generated mod, without opening the FDB.

    Saving replaces the table in one transaction — a UNIQUE clash rolls the whole edit back rather than leaving the mod half-written.
